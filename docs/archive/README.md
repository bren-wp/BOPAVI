# Historical BOPAVI development records

These files are preserved for audit traceability. They describe former
versions, retired iOS code, removed UI, older screenshot studies or
superseded QA plans. **None is an active implementation or release guide.**

For the current Android-only project use `README.md`, `QA.md`,
`docs/android/ARCHITECTURE.md`, `docs/qa/` and
`docs/play/RELEASE-CHECKLIST.md`. Stable GitHub releases are retained
without rewriting published tags or artefacts.
